README

To replicate the results reported in the paper, simply source the R script provided.  In the preamble of the R script, information about all packages necessary to execute the analysis is provided.  

The R script will access the replication dataset, conduct the analysis reported in the paper, and will output the figures reported in the paper.  

For questions, contact the authors Ransi Clark (tweeraso@caltech.edu) or R. Michael Alvarez (rma@caltech.edu).
